# Android 배포 준비 메모

## 1. 현재 가능한 배포 방식

### A. APK 직접 설치
- 서명된 APK 파일을 공개 링크로 배포
- 가장 간단한 방식:
  - GitHub Releases asset 링크
  - `/install/android` 페이지에 연결

### B. Google Play Internal testing
- 정식 출시 전 가장 안전한 방식
- signed AAB 업로드 후 소수 사용자부터 테스트

## 2. 현재 빌드 산출물

- APK: `android/app/build/outputs/apk/release/app-release.apk`
- AAB: `android/app/build/outputs/bundle/release/app-release.aab`

## 3. Google Play Console 등록 체크리스트

- 개발자 계정 준비
- 앱 생성
- 앱 이름/기본 언어 설정
- 패키지명 확인: `com.snh.deliverymap`
- 개인 정보 보호정책 URL 준비
- 앱 카테고리/연락처 정보 입력
- 데이터 보안(Data safety) 작성
- 테스트 트랙(Internal testing) 생성
- signed AAB 업로드

## 4. 스크린샷 준비 권장

### 모바일 필수 샷
- 메인 홈 화면
- 도착지 입력 + 추천 방문 순서
- 네이버 지도 + 팬 오버레이
- 운임 계산기
- 관리자 OCR/개발요청은 내부 기능이라 일반 스토어 스크린샷에는 제외 가능

### 스크린샷 포인트
- 앱 이름 `퀵·배달 구역메이커`
- 출발지 자동 인식 / 다중 도착지 / 길찾기 / 동 리스트가 잘 보이도록

## 5. 스토어 설명 문구 초안

### 앱 이름
- 퀵·배달 구역메이커

### 짧은 설명
- 퀵/배달 다중 경로, 동 리스트, 길찾기와 운임 계산을 한 번에

### 긴 설명
- 퀵·배달 구역메이커는 퀵서비스와 배달 업무를 위한 실무형 경로 보조 앱입니다.
- 현재 위치를 기준으로 여러 도착지를 입력하고, 추천 방문 순서와 구역(동 리스트)을 빠르게 확인할 수 있습니다.
- 네이버 지도, 카카오 지도, 카카오내비 길찾기를 지원하며, 운임 계산과 일일 통계도 함께 관리할 수 있습니다.
- 주요 기능:
  - 현재 위치 기준 출발지 자동 인식
  - 다중 도착지 입력과 추천 방문 순서
  - 팬(부채꼴) 권역 기반 동 리스트 생성
  - 네이버/카카오/카카오내비 길찾기
  - 운임 계산기와 일일 통계
  - 관리자 승인 기반 접근 관리

## 6. 배포 전략 추천

2. 내부 사용자 테스트
3. Google Play Internal testing
4. 문제 없으면 정식 출시
